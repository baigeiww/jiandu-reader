笺读 0.4.0 · Mac 原生论文阅读器

适用于 Apple Silicon（M1 及更新芯片），macOS 13 或更新系统。

1. 将「笺读.app」拖入 Applications，再推出磁盘映像。
2. 从「应用程序」启动笺读。应用已内置运行环境，无需安装 Node.js。
3. 如果 macOS 阻止首次打开，请在启动一次后，前往「系统设置 → 隐私与安全性」，核对应用来源后选择「仍要打开」。此版本采用本机临时签名，尚未通过 Apple 公证。
4. 导入论文 HTML 全文链接或 arXiv 编号，即可开始阅读。AI 功能请在「翻译设置」中配置自己的服务、模型和 API Key，并测试连接。

升级时先退出旧版笺读，再替换应用。原生版沿用同一应用标识，本机阅读数据会继续使用。跨客户端迁移请先导出、再导入阅读数据。

阅读库和手动填写的 API Key 保存在本机。备份也可能包含 API Key，请妥善保存。翻译、公式解释会将所需论文片段发送至你选择的服务。论文图像可能仍需联网加载。

应用使用本机端口 5173，关闭最后一个窗口即退出服务。若提示端口被占用，请先退出旧版或停止该端口上的开发服务。
