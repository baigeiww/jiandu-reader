# 笺读 v0.4.1

本版修复论文切换和导入栏操作，并新增 Frontiers 公开全文支持。适用于 Apple Silicon Mac（M1 及更新芯片），macOS 13 或更新系统。

## 本版更新

- **切换论文不再跳侧栏**：在「我的藏书」中选择其他论文后，继续显示藏书列表；只有手动点「论文目录」才切换视图。
- **导入栏可以收起**：右上角「＋」再次点击即可收起，也可点击栏内关闭按钮或按 Esc。未提交的网址会保留，当前论文仍可阅读。原生菜单 `⌘O` 继续用于打开导入栏。
- **支持 Frontiers**：可粘贴文章的 full、abstract 或 pdf 链接，统一读取公开全文。使用官方 XML 还原正文、章节、公式、表格、图表说明及参考文献，图片使用原站资源；支持双语阅读、图注翻译、公式解释和引用跳转。
- **修正来源信息及 PDF 链接**：Frontiers 显示文章 DOI，PDF 按钮指向对应原站 PDF。

已使用《Review of the BCI Competition IV》（DOI：10.3389/fnins.2012.00055）验证导入、公式、图表和引用。其余站点的支持范围见仓库 README；Frontiers 原站内容和图片需要可正常联网访问。

## 下载与安装

下载本页附件 `Jiandu-0.4.1-macOS-arm64.dmg`，打开后将「笺读」拖入「Applications」，推出磁盘映像，再从「应用程序」启动。应用已包含运行环境，无需另装 Node.js。

本版采用本机临时签名，尚未通过 Apple 公证。若 macOS 阻止首次启动，请先尝试打开一次，再在「系统设置 → 隐私与安全性」核对来源并选择「仍要打开」。[Apple 的打开说明](https://support.apple.com/zh-cn/102445)

## 升级与数据

先退出旧版，再用新版替换应用。应用标识保持为 `com.baigeiww.jiandu-reader`，沿用原生版的本机论文库、译文和设置；建议升级前在「我的藏书」导出阅读数据。从 Electron 或网页版迁移，请在旧客户端导出后再导入新版。

AI 功能需要配置自己的服务、模型和 API Key；请求会发送相关论文片段至所选服务。手动填写的 API Key 以明文保存在本机，导出的阅读数据也可能包含密钥，请妥善保存。

## 校验安装包

同时下载 `SHA256SUMS.txt`，在下载目录执行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

完整功能、快捷键和源码构建方式见 [README](https://github.com/baigeiww/jiandu-reader#readme)。
