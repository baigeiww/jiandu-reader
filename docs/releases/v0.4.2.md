# 笺读 v0.4.2

修复图表说明译文与正文译文的颜色区分。适用于 Apple Silicon Mac（M1 及更新芯片），macOS 13 或更新系统。

## 本版更新

- **图表译文恢复独立配色**：正文译文保持暖棕色，图表说明译文使用柔和灰紫色，文字、底色、边线和标签均有区分。
- **浅色与深色模式均生效**：修复后续主题规则覆盖图表配色的问题，双语和译文视图均采用独立图表配色。
- **已有译文直接生效**：本次调整仅更新界面样式，无需重新翻译；保留本机论文、译文、分组、API 配置和阅读设置。
- **验证可读性**：使用 Mac 系统 WebKit 检查两种主题及阅读视图的实际颜色，图表译文文字与标签的对比度均达到 4.5:1。

继续包含 v0.4.1 的 Frontiers 公开全文支持、导入栏收起，以及切换论文时保留侧栏视图等修复。

## 下载与安装

下载本页附件 `Jiandu-0.4.2-macOS-arm64.dmg`，打开后将「笺读」拖入「Applications」，推出磁盘映像，再从「应用程序」启动。应用已包含运行环境，无需另装 Node.js。

本版采用本机临时签名，尚未通过 Apple 公证。若 macOS 阻止首次启动，请先尝试打开一次，再在「系统设置 → 隐私与安全性」核对来源并选择「仍要打开」。[Apple 的打开说明](https://support.apple.com/zh-cn/102445)

## 升级与数据

先退出旧版，再用新版替换应用。应用标识保持为 `com.baigeiww.jiandu-reader`，沿用原生版的本机论文库、译文和设置；建议升级前在「我的藏书」导出阅读数据。从 Electron 或网页版迁移，请在旧客户端导出后再导入新版。

AI 功能需要配置自己的服务、模型和 API Key；请求会发送相关论文片段至所选服务。手动填写的 API Key 以明文保存在本机，导出的阅读数据也可能包含密钥，请妥善保存。

## 校验安装包

同时下载 `SHA256SUMS.txt`，在下载目录执行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

完整功能、快捷键和源码构建方式见 [README](https://github.com/baigeiww/jiandu-reader#readme)。
