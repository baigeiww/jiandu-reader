# 笺读 v0.4.0

Mac 原生论文阅读器，适用于 Apple Silicon Mac 和 macOS 13 或更新系统。

## 下载与安装

下载本页附件 `Jiandu-0.4.0-macOS-arm64.dmg`，打开后将「笺读」拖入「Applications」。应用已包含运行环境，安装后可直接启动。

本版采用本机临时签名，尚未通过 Apple 公证。若 macOS 阻止首次启动，请在尝试打开后，前往「系统设置 → 隐私与安全性」核对来源并选择「仍要打开」。

## 本版更新

- 使用 AppKit 窗口和系统 WebKit，整理应用图标、原生工具栏及暖色浅色、深色界面。
- 优化阅读区域和论文存储，减少长文滚动及切换视图后的内存占用。
- 侧栏支持收起、展开和调宽，记住收起状态，支持原生菜单与 `⌃⌘S`。
- 修复窄窗口下宽图、多子图及固定宽度容器造成的图片裁切。
- 点图可查看完整图片，支持键盘进入、Esc 返回并恢复焦点，预览按需创建。
- 保留混有代码与图片的图组，避免导入时误删图像。
- 改进模型配置、连接测试、请求读取、数据导入和本机服务处理。
- 修复应用识别，补齐图片、公式和设置的辅助功能与键盘操作。

## 开始阅读

导入 arXiv 编号或受支持的 HTML 全文链接，在原文、双语与译文间切换。AI 功能需要在「翻译设置」中配置自己的服务、模型与 API Key。可先使用内置示例体验界面。

## 升级与数据

替换应用前先退出旧版，建议导出阅读数据。新版沿用原生版的应用标识和本机阅读库。从 Electron 或网页版迁移时，请先在旧客户端导出，再在新版导入。

备份可能包含手动填写的 API Key。AI 请求会发送相关论文片段至所选服务。图片及原站资源可能需要联网加载。

## 校验

下载 `SHA256SUMS.txt`，在安装包所在目录执行 `shasum -a 256 -c SHA256SUMS.txt`。

详细功能、快捷键和源码构建方式请见仓库 README。
