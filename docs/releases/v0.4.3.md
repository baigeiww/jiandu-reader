# 笺读 v0.4.3

翻译任务面板支持最小化、关闭和状态选择，同时保留图表译文独立配色。适用于 Apple Silicon Mac，macOS 13 或更新系统。

## 翻译任务面板

| 操作或当前状态 | 结果 |
| --- | --- |
| 点击「−」或面板标题最小化 | 只缩小面板，任务状态不变；点击标题或底栏「翻译任务」恢复 |
| 运行、排队或正在暂停时点击「×」 | 先选择关闭方式，不会直接取消请求 |
| 选择隐藏面板 | 运行任务继续后台翻译；暂停或异常任务保持状态；底栏可恢复查看和操作 |
| 选择暂停并关闭 | 当前项保存后暂停，排队任务立即暂停，之后可继续补齐未译项 |
| 选择取消并关闭 | 取消未完成任务，中止正在请求的项，保留已保存译文；之后可重新发起批量翻译补齐 |
| 已暂停或异常时点击「×」 | 可隐藏并保留任务，或取消；不会自动继续请求 |
| 已完成或已取消时点击「×」 | 直接移除任务记录，论文和已保存译文保留 |

任务进行中，关闭选项会随实时状态更新。若任务恰好在保存时被取消，已开始的保存可以完成，任务仍正确显示「已取消」。

任务队列只在本次应用会话中运行。关闭面板不会退出应用；退出应用后，已保存译文仍保留，可以重新发起批量翻译补齐未译项。失败项可以重试；移除任务记录后，也可通过批量翻译补齐。

## 图表译文配色

包含 v0.4.2 修复：图表说明译文使用灰紫色，正文译文保持暖棕色，文字、底色、边线和标签均有区分。浅色、深色以及双语、译文视图均有效；已有译文直接采用新配色，无需重新翻译。

## 下载与安装

下载本页附件 `Jiandu-0.4.3-macOS-arm64.dmg`，打开后将「笺读」拖入「Applications」，推出磁盘映像，再从「应用程序」启动。应用已包含运行环境，无需另装 Node.js。

本版采用本机临时签名，尚未通过 Apple 公证。若 macOS 阻止首次启动，请先尝试打开一次，再在「系统设置 → 隐私与安全性」核对来源并选择「仍要打开」。[Apple 的打开说明](https://support.apple.com/zh-cn/102445)

## 升级与数据

先退出旧版，再用新版替换应用。应用标识保持为 `com.baigeiww.jiandu-reader`，沿用原生版的本机论文库、译文和设置；建议升级前在「我的藏书」导出阅读数据。从 Electron 或网页版迁移，请在旧客户端导出后再导入新版。

AI 功能需要配置自己的服务、模型和 API Key；请求会发送相关论文片段至所选服务。手动填写的 API Key 以明文保存在本机，导出的阅读数据也可能包含密钥，请妥善保存。

## 校验安装包

同时下载 `SHA256SUMS.txt`，在下载目录执行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

完整功能、快捷键和源码构建方式见 [README](https://github.com/baigeiww/jiandu-reader#readme)。
